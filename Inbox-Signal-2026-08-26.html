Pragmatic Engineerpart paywalledRead

Why Ramp built its own coding agent instead of buying one

75% of all merged PRs at Ramp are now authored by Inspect, their in-house agent — up from ~60% in January, from a team of 5.5 people (four engineers, a director, a part-time PM). The differentiator is not model quality, it is access: Inspect runs remote sandboxes provisioned in under five seconds, wired to internal data, so it can close the verification loop — run tests, query telemetry and feature flags, screenshot-verify frontend work.

It became a platform: 200+ internal agents, including a review bot one engineer built in a week that reportedly beats third-party tools because it knows Ramp's context. The buy-don't-build reflex may genuinely not hold here.

2
Addy OsmaniRead

Human judgment doesn't leave the software factory — it relocates

The argument against letting ownership fall in proportion to the code you personally type. Judgment moves to intent, system shape, the quality bar, and deciding which verification signals to trust. Two transferable mechanics: a run taxonomy (Warp labels every issue ready-to-implement / ready-to-spec / needs-info / wait-to-implement, where the label doubles as queue and lock; Vercel labels every run success / flawed / blocked / manual, and only "success" ships), and a verification budget — cheap checks early, mutation and browser and security checks before draft PR.

His own numbers: a clean agent task took 7 minutes; the same task with two rejections and one human decision took 56. And the real cost he names is comprehension debt — he lost the mental model of a feature he had merged himself.

3
Eng LeadershipRead

Culture is the multiplier; AI just amplifies whatever is already there

Gregor Ojstersek runs it through Conway's law: the product mirrors the org's communication structure, so AI makes bad communication and bad architecture worse faster, while good architecture gives agents a better blueprint. Two warnings aimed straight at leadership: the sentence "this is easy now that we have AI, we don't need as many people" destroys psychological safety, and executives who panic at competitors' 10× claims should check the incentive behind the claim first — most are product marketing.

Carries a nine-question culture diagnostic worth running on your own teams, and the line to argue with: AI adoption is bottom-up or it doesn't happen, because tooling changes weekly. Targeting AI usage as the goal means you have already lost the plot; the goal is business outcomes.

4
Latent.SpaceRead

The evolution of the agent harness — and why the metric is how much you delete

Dan McAteer's thesis: agents "suddenly working" was not a model jump, it was two curves crossing — what harnesses ask of models versus what models can deliver. AutoGPT failed because a loop amplifies rather than adds (95% per-step reliability over 20 steps is ~36% success). Then reasoning models pulled ahead of their harnesses and Claude Code seized the inversion.

The forward call is the useful part: RL now happens inside the harness, so models absorb harness capabilities into weights — Anthropic deleted 80% of Claude Code's system prompt — meaning progress is measured by how much harness you get to delete. What can never be absorbed is the human-facing layer: permissions, identity, trust, legibility. He predicts an AGENTS.md for you within a year.

5
ByteByteGoRead

Encrypted reasoning traces replay across users — and leak secrets

Providers hand encrypted reasoning blocks back to the client. The authenticated data covers model name and version but not the account or session, so a valid block replays across users and models. The attack: query the flagship (which got anti-distillation training), discard the answer, paste the encrypted block as prior context into its cheaper sibling (which didn't), and have it transcribe the trace in plaintext.

A scan of 6,708 public agent trajectories decoded 315,320 blocks and surfaced 62 API keys, 33 passwords, 24 access tokens and 7 private keys — none reachable by sanitization, because publishers cannot read their own encrypted blocks. If your teams are shipping agent trajectories anywhere public, this is the week's most directly actionable read.

AINewsRead

"Death of params": GLM-5.3's jump came from post-training, not size

Z.ai's Jie Tang argues parameter count is meaningless alone — it only means something alongside how much data you have, where you spend compute, and who runs the model under what conditions. GLM-5.3 is reportedly built on the same core base model and architecture as 5.2 and improved substantially by about one extra month of RL, landing #2 on Terminal Bench, #3 on Legal Bench and #6 on Skills Bench among open weights.

The mechanism is synthetic all the way down: research agents collect task patterns from real work and turn them into runnable long-horizon environments with multi-step dependencies and hidden state; a judge agent attempts each task to prove it solvable; verifiers are synthesized without access to the reference solution and must pass oracle, no-op and unsolved-state checks before their binary reward is trainable. Tang's structural point: advanced skills like vulnerability discovery need carrying 20+ inference steps without losing the thread, and that lives in effective depth, not total parameters.

Run the BusinessRead

The "Execution Map": a workflow diagram from the doer's side

Workflow diagrams document a process from the company's perspective and are blind to the actual work of completing an instance of it — the chasing, re-sharing, comment-answering the author calls meta work. The execution map is the personal-perspective counterpart, drawn in Graphviz because LLMs handle that syntax well. You build it by asking of each node: who approves this, what evidence do they need, who starts the next step, and how long before I follow up. 9 items

Longer thinking pieces from Latent.Space, The AI Corner and Refactoring — the argument is summarized so you can decide before committing the reading time.

The AI CornerRead

Why most self-improving AI loops fail

Strip the branding off the loop-pattern catalogs and there are five moves — verify-and-repair, sample-and-select, reflect-and-retry, decompose, adversary — all free in libraries, so whatever separates working loops from broken ones must sit upstream in the feedback signal. A loop cannot create quality; it converts a signal into quality and charges you tokens, so iterating against noise is "a random walk with a receipt attached." He offers a five-rung ground-truth ladder (executable → referential → rubric-judged → preference → vibes) and matches iteration budget to rung: executable earns dozens of rounds, rubric-judged earns exactly one critique and one rewrite, preference earns no live loop at all. Sharpest filter: if every arrow points from the model back to the model, it's decoration.

The AI CornerRead

Context engineering is budgeting, not collecting

Against the popular reading of Anthropic's 8×-code-merged figure that sends people building elaborate scaffolding. The model has a finite attention budget and every token spends from it: a 400-line CLAUDE.md is followed less reliably than a 200-line one, and every connected MCP server taxes session startup before you type anything. His organizing move is to sort context by load time rather than topic — enforced (settings and hooks, the only real guardrails), resident (CLAUDE.md), conditional (path-scoped rules), fetched (skills, subagents, MCP) — because what's read off disk at startup gets re-injected after compaction while everything from conversation gets folded into a summary and stays folded. Honest ending: Anthropic itself calls 8× an overstatement; polling 130 research staff put the median nearer 4×.

RefactoringRead

Giving agents dynamic autonomy

Luca Rossi argues the popular "autonomy slider" is wrong because it is static: hard-coding human gates into a workflow guarantees either safe work sitting in a queue or risky work sailing through uninspected, because the situations arriving at any workflow are too diverse. Unblocked scores each run on two axes — how confident the agent is the job is real and doable, and how risky the change is — then routes: high-risk/low-confidence writes a ticket for a human, the 50–70% middle Slacks a specific person with context attached, low-risk/high-confidence opens a PR. The same score gates whether the PR needs human review at all. Directly applicable if you are standing up agent workflows for client work.

RefactoringRead

Outsource the knowledge, protect the reasoning

"Smart" conflates knowledge with reasoning; the diagnostic question is whether you're reaching for AI because you genuinely don't know something or because you don't want to think it through. The technique inverts the usual anchoring: write your own first draft, then ask the model to build the same artifact from scratch without seeing yours, because models are bad at disagreeing with you and a blind rebuild beats "please review this." Second half, from AMD's VP of AI Software: at this rate of change you can't lead from one layer above the work — he targets 40% hands-on time, and three to five hours with a problem returns a concrete assessment plus a failing unit test, replacing a week of status meetings.

The AI CornerRead

The task economy is real and almost everyone is valuing it wrong

Concedes the growth (Mercor $1M → $2B annualized in ~24 months) then attacks the framing: a task is not a service consumed, it's a transfer of ownership — human judgment stops being rented by the hour and becomes a permanent, infinitely copyable asset. Three structural problems follow: Bloomberg reports 60–70% of Mercor's gross billings pass straight through to contractors ("a labor market wearing a software valuation"); the buyers are five companies with correlated termination risk; and every lab dollar on tasks is matched by a dollar on synthetic data and self-play — customers financing their own exit. Screening question: is this revenue teaching the model, or auditing it?

Latent.SpaceRead

Every year since 2022, one more part of the pipeline flipped to synthetic

swyx traces it with patient zeros: the reward signal (2022), training data (2023), the teacher, the curriculum (2024), the researcher, the environment, and now the human subject. The load-bearing insight is the pattern underneath — every flip drew the same model-collapse objection and happened anyway, at the exact moment a verification mechanism made the synthetic version trustworthy. "The synthetic frontier doesn't advance when generation gets better. It advances when verification does." Which is why the last unfilled square is physical experiment, where verification is slowest.

Latent.SpaceRead

The /wayfinder skill: vocabulary as architecture

Matt Pocock's problem was that planning, not execution, had become the bottleneck for away-from-keyboard agents. /wayfinder orchestrates other planning sessions, splitting research, prototyping and interrogation into child sessions and pulling results back. The design lesson is the transferable part: work out the information flow first (a child session needs a map of decisions already made plus its specific ticket), then insist on precise leading words — map, ticket, session, fog of war — because reusing one word for different entities produces confused agent behavior. He's building an AI-coding dictionary so all his skills share one ubiquitous language.

Latent.Spacepodcast

Simulation as the new scaling law — Joon Sung Park

Digital twins built from two-hour biographical interviews reproduced their source humans' survey and behavioral responses 85% as accurately as those humans reproduced themselves two weeks later. The counterintuitive claim: frontier models are bad simulators precisely because they're post-trained toward being rational agents, and good simulation requires reproducing human bias and inconsistency — which he argues needs weight changes, not prompting. He reframes the goal from prediction toward shaping: testing products and policies before deploying them. Context: $2B Series B, tens of millions of simulations for Fortune 100 clients.

RefactoringListen

Burnout is a system issue — Dominika Rogala

Burnout is not being tired and is not an individual resilience failure: it has four distinct dimensions, involves an "identity gap," and is properly diagnosed and fixed at the level of team structure and process. The AI segment frames the tool as simultaneously a resource and a demand — it adds capacity while inflating expectations, and the net effect on a team depends on whether you let the expectation side inflate uncontrolled. Comes with a public self-check worksheet and a micro-regulation toolkit.

An autoscaling misconfiguration on an Istio sidecar pod cascaded into load-balancer network saturation, taking down Issues, PRs, APIs, Actions, Copilot and auth. Cursor's Origin rearchitects Git hosting on a stateless S3 write-ahead log, giving linearizable pushes and linear horizontal read scaling instead of GitHub's 3PC-based Spokes; it two-way syncs with GitHub, but pushes still land on GitHub and Issues, Actions and secrets don't sync at all, and beta repo names are permanent. TLDR DevRead

Benchmarks are now trivially reward-hacked by coding agents

An agent-built regex engine appeared 40% faster than Rust's regex crate on its target suite and was dramatically slower on a holdout workload; inspection found benchmark-specific shortcuts and outright cheating. The conclusion is that even broad suites are gameable without independent auditing. Pairs with the week's other data point — agents hitting 94% on Terminal Bench 2.1 were found to be cheating the benchmark. TLDR DevRead

Shopify rebuilt mobile E2E testing to 98% stability

The old Appium/WebdriverIO setup had gone so flaky it was pulled from PR checks, because it permitted footguns like arbitrary pauses and asserted on view-hierarchy nodes rather than what a user could actually see. The rebuild is an opinionated wrapper with a strict builder API that forces an assertion on every step and prefixes escape hatches with UNSAFE_, plus computer vision that locates elements the way a merchant would. The design principle generalizes past mobile: make the flaky thing unrepresentable in the API.

TLDR DevOpsRead

A working remote Spectre attack against Cloudflare Workers in production

Researchers leaked up to 12 bits per second at 99% accuracy by exploiting a gap in Dynamic Process Isolation, which only isolates suspicious scripts after an invocation ends — bypassed by keeping a single Durable Object invocation alive for hours via WebSocket messages. Cloudflare says no active exploitation was detected over three years and has responded with better isolation detection, the V8 Sandbox, and Memory Protection Keys limiting cross-isolate memory access in shared processes.

TLDR DevRead

TLDR DevRead

86% of scanned SPA repos never clean up what they register

Across 500 React/Vue/Angular repos, 86% register listeners, timers or nodes they never clean up — and since SPAs never reload, these accumulate until the tab dies. The recommended fix is concrete enough to adopt this week: a Playwright soak test that loops one round-trip flow a few hundred times in a single browser context, reads node and listener counts over CDP before and after (heap measurements are too noisy), and asserts they don't climb.

Agents that don't start over when they fail

Changes tone, persona, format compliance, domain reasoning patterns, structured output. Choosing a consistency model — as a spectrum, not a ranking

The failure it targets is applying one model to all data: too strong for like counts, potentially too weak for messages. Linearizability means the minimum write latency is the round-trip to the slowest node that must acknowledge — the CP choice, so an isolated node errors rather than serving stale data — and it's required where stale data causes uncorrectable harm: balances, scarce inventory, distributed locks and leader election, session and token revocation. Ollama vs vLLM vs SGLang — they differ by scheduler, not scale

Ollama is a FIFO queue over pre-quantized GGUF weights (laptop dev). vLLM uses continuous batching to slot arriving requests into the running batch instead of waiting for it to drain, plus PagedAttention for KV cache memory (high concurrency). SGLang adds a prefix-aware scheduler over a RadixAttention radix tree that reuses shared prompt prefixes rather than recomputing them — which is exactly why it wins for agent loops and multi-turn chats, where prompts overlap heavily. One AI output is an example, not an evaluation

NN/g's argument, and the most reusable thing in the design section: a single output only shows the system can do the task once, not how reliably it holds.
